A rule I would set now, before this gets away from us.

A mark earns its place when it means something: a question mark on questions, a tick on inclusions, braces on the engineering paragraph. The moment one is there because the space looked empty, the whole set stops reading as a language and starts reading as clip art. One mark per section, maximum, and never two in the same eyeful.

This is the better of the two, and not only as a compromise. Pure WK4 asks a first-time visitor to hover before they see any work at all, which is a lot of faith to ask for. Here the strongest project is on screen immediately and the discovery applies to the rest. It also solves the phone problem: with no pointer, the featured project still lands and the index is simply a list.

One thing to decide: whether the featured project is always Swirly, or whether it follows order so you can promote whatever you want to lead with by changing one number. I would do the latter. It costs nothing and it means the home page can be reshuffled without touching any code.
