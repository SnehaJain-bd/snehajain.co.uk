WK4

Hover the names. The type carries the page and the images only appear when someone reaches for them. It is the most confident of the four and the most in keeping with the cursor field, since both make the pointer part of the design. The real cost is that on a phone there is no pointer, so it has to fall back to WK3 or WK1 entirely.

My reading: WK3 if you want the home page to argue, WK4 if you want it to be remembered. WK2 is lovely and too tall for a home page, though it would be excellent on /work itself, where length is the point.

Twelve rows that open

  • Logo, type, colour and imagery built as a system, so your brand looks like itself everywhere.

My reading: SV2. It is the only one where the shape of the section tells the same story as the sentence above it, and you would not have written that sentence if it were not true.
