Images for this project.

Drop your files straight in here. The build picks them up automatically,
so there is nothing to type in the editor.

  cover.jpg            the wide image at the top of the case study,
                       and the thumbnail in the work grid.
                       If there is no cover file, the first file
                       alphabetically is used instead.

  anything else        joins the gallery below the text, in filename
                       order. Number them to control the order,
                       for example 01-logo.jpg, 02-pattern.jpg.

  a name with "wide"   spans the full width instead of sitting two up,
                       for example 04-range-wide.jpg.

Alt text comes from the filename, so 03-pattern-detail.jpg reads as
"pattern detail" to a screen reader. Name files in plain words.

About 1600px wide, exported as JPEG, is the right size.
